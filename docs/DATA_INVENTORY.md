# Public data inventory

## Published datasets

| Dataset | Purpose and source | Personal-data policy | Retention and deletion |
|---|---|---|---|
| `data/latest_changes.json` | Latest Discord client experiment, localization, and REST-route changes generated by the private runner | Product metadata only; user records and raw messages are prohibited | Replaced on each successful publication; prior versions remain in public Git history |
| `data/web/*.json` | Read-optimized experiment, localization, route, and count datasets for discord-archive.com | Product metadata only; exact, reviewed Discord-authored literals may be temporarily allowlisted | Current files are regenerated; prior versions remain in public Git history |
| `data/reports/**/*.json` and `*.md` | Human-authored interpretation of already-public product metadata | No raw Discord messages, moderation exports, contact details, or account identifiers | Retained as dated public research reports |

## Data that must stay private

The following belong only to the private runner checkout and must never be
published here: `history.json`, `previous_state.json`, `message.txt`, extracted
string baselines, raw API/experiment state, Canary bundles, credentials,
cookies, request headers, full exception payloads, quarantine artifacts, and
moderation or user-message reports.

The runner's failed publication candidates and redacted scan reports are kept
outside this repository in its ignored local quarantine directory for at most
30 days. They are not committed or pushed.

## Recipients and access

Published files and their Git history are public to anyone. The website may read
the `data/web` files and the bot may read `data/latest_changes.json`. No other
recipient is authorized for private runner state. Removing a public Git artifact
does not erase earlier Git history, so the pre-publish scanner is the primary
privacy boundary.
